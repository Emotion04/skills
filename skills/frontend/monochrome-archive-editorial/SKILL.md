# 黑白数字档案馆界面

把网页设计成一座安静的信息馆：纯单色、衬线标题、发丝分隔线、大量留白，让数据像展品而不是仪表盘。

## 快速开始

生成页面前，先读 [REFERENCE.md](REFERENCE.md)。然后确定：内容类型、时间跨度、Tab、统计字段、是否需要搜索/暗色模式/阅读浮层。

可直接使用以下提示词：

```text
请设计并实现一个「[主题]」网页，采用克制的黑白数字档案馆 / 编辑部风格。
页面结构：透明模糊的 sticky 顶栏；居中的超大衬线 Hero；带平滑滑动下划线的 sticky Tab；
概览页包含叙事性引言、四项数据统计和年度轨迹；时间轴按年份分组，年份标题 sticky，
用发丝竖线连接节点；内容页按年份归档；长文在居中阅读浮层打开。

视觉要求：只用黑、白、灰和语义化 CSS 变量；大量留白；1px 发丝边框；
胶囊控件用 999px 圆角，其余卡片只用 2-3px 小圆角；不使用彩色渐变、厚重阴影、
大面积卡片堆叠或夸张动效。展示标题/正文用中文衬线体，UI 用无衬线体，日期和统计用等宽体。

交互要求：Tab 下划线根据 active 项的 offsetLeft/offsetWidth 平滑移动；切换视图淡入并上移 8px；
hover 只做边框增强、轻微位移或浅灰底；支持 URL hash、键盘 Esc、明暗主题、
prefers-reduced-motion 和移动端适配。所有按钮有可访问名称与清晰 focus 状态。

请先给出信息架构和设计 token，再输出可运行的 [技术栈] 代码。不要照搬示例文案，
但严格保持这种「安静、硬朗、文学化、以内容为中心」的设计气质。
```

## 实施流程

1. 先用真实内容层级建信息架构，不先画卡片。
2. 建立 `bg / fg / muted / faint / line / line-2 / shadow` 双主题 token。
3. 按 `serif=叙事、sans=操作、mono=数据` 分配字体。
4. 实现 Hero、Tab、概览、时间轴、归档列表，再补浮层和设置。
5. Tab 指示线必须测量真实按钮位置，不用写死百分比。
6. 时间轴用三列网格：日期、轨道、正文；年份标题保持 sticky。
7. 最后检查移动端、键盘操作、暗色模式和减少动效偏好。

## 风格守则

- 用留白和排版制造高级感，不靠装饰。
- UI 是展陈框架，内容才是视觉主角。
- 用线分组，少用独立浮卡；阴影只属于浮层。
- 动画保持 `.2-.5s`，使用平稳 ease，不弹跳、不炫技。
- 文案应像档案标签或展览说明，简短、准确、略带文学性。
- 如现有项目已有设计 token 和组件模式，优先继承，不另造体系。
